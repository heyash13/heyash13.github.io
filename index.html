VULNERABILITY ADVISORY · GOOGLE ANDROID VRP SEPTEMBER 2026 · RATED MODERATE SEVERITY BY ANDROID SECURITY TEAM

Thread-Safety Race Condition in Android Conscrypt (BoringSSL JNI Wrapper) Leading to Native Use-After-Free / SIGSEGV

Google Android Vulnerability Reward Program (VRP) · Verified & Passed to Feature Team for Remediation

Discovered and reported a concurrency synchronization flaw in Conscrypt (Android's Java Cryptography Architecture provider backed by native BoringSSL via JNI). Specifically, methods such as exportKeyingMaterial() dereferenced the underlying native ssl pointer without acquiring the required read lock.

When a concurrent thread invoked close() on the socket/engine, BoringSSL freed the native memory structure while exportKeyingMaterial() was mid-execution, triggering a deterministic native SIGSEGV (segmentation fault) and crashing the host Android runtime process.
